How to Set Up Server Mode

Local Mode: Everything works on this device only. Perfect for testing.

Server Mode: Data syncs with your backend. Multiple people can use it.


To enable Server Mode:

  1. Deploy the backend code I provided
  2. Enter your server URL above
  3. Test the connection
  4. Switch to "Server Mode" in the header
